# DFE - Provisório

Ferramenta para manutenção de arquivos fiscais com suporte de extensões para geração de arquivos fiscais, como SPED.

# Funcionalidades

- Manutenção de arquivos XML (remoção de duplicatas, organização, classificação);
- Geração de arquivos fiscais como SPED, Sintegra e inventário;
- Geração de relatórios;
- Envio dos arquivos por e-mail;
- Manifestação do destinatário (MD-e);

# Tecnologias utilizadas

- C++;
- Qt;
- CMake;
- PostgreSQL;
