1. Novo arquivo é detectado
2. Se este arquivo é um .xml, salvo o caminho absoluto em uma tabela chamada arquivos, que possui 3 campos, caminho, nome_arquivo e processado
3. APós isso, disparo um novo evento acionando o worker a percorrer os arquivos pendentes.
3.1 A tarefa do worker será a seguinte: Ele deverá ler o arquivo, identificar qual o modelo de documento ele se refere, baseado na tag de mais alto nível, além de campos como modelo (para distinguir NF-e de NFS-e, por ex). E preencher as tabelas de acordo com os dados do XML (dfe, dfe_itens, etc)
3.2 Se a nota for emitida pela empresa usuária do sistema, este produto deve ser cadastrado automaticamente como produto e, caso haja algum produto em notas de fornecedores onde o código de barras seja equivalente, o sistema deve fazer a associacão do produto.
3.2.1 Os produtos serão únicos por cód de barras, porém poderão ter mais de um codigo_interno (situacões onde o cliente pode ter tido multiplos sistemas com códigos_internos distintos em cada um).
